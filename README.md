# gye-query-write · 通达信外部数据查询写入工具集

交易日自动运行的通达信数据写入工具集：查询市场数据 → 写入通达信外部数据 `extern_user.txt` / 标记文件 `mark.dat`。

## 工具列表

| 工具 | 功能 | 写入目标 | 触发 |
|------|------|---------|------|
| `gye.py` | 隔夜单（竞价买盘占比）6时点查询 | extern_user.txt ID 115/125/126/127/128/116 | 交易日 9:27 |
| `update_markdat.py` | 涨停原因查询写入 | extern_user.txt ID=108 + mark.dat [MARK]=7/[TIP] | 盘后手动 |

## gye.py · 隔夜单查询写入

隔夜单（集合竞价买盘占比）查询与写入工具：交易日 **9:27** 自动运行（cron），抓取竞价阶段买盘挂单强度，写入通达信外部数据 `extern_user.txt`。

### 6个时点查询（买盘挂单量×100÷自由流通股）

| 时点 | ID | 挂单位置 | 含义 |
|------|-----|---------|------|
| 9:15 | 115 | 买二 | 当天隔夜单（核心） |
| 9:18 | 125 | 买二 | 918占比 |
| 9:20 | 126 | 买二 | 920占比 |
| 9:23 | 127 | 买二 | 923占比 |
| 9:24 | 128 | 买二 | 924占比 |
| 9:25 | 116 | 买一 | 当天开盘占比 |

- 数据源：同花顺问财（`9点15分买二*100/自由流通股>0.1` 等）
- 筛选：任一查询返回占比 >0.1 的股票入池
- 限频：每次查询间隔 350ms

### 写入格式（通达信 extern_user.txt）

`市场标志|代码|ID||占比值`，GBK 编码
- 市场标志：6/8开头→1(沪/科创)，0/3开头→0(深/创业)，9开头→2(北交所)
- 覆盖策略：写前先删旧的 115/125/126/127/128/116 行，再追加新行（其它ID数据保留）
- NaN/0 值自动跳过

### 附加动作

隔夜单占比(ID=115) TOP5 自动合并进通达信【复盘 FUPAN】板块（保留已有个股）。

## update_markdat.py · 涨停原因标记写入

查询当日涨停板块及每只涨停股的「涨停原因揭秘」长文本，清洗后写入通达信自定义外部数据 ID=108（涨停原因列）+ 标记文件 mark.dat。

### 数据源（主备双通道）

- **主力**：通达信问小达 TQL API（Playwright 页面上下文调用，分页每页100条）
- **备选**：thsdk 同花顺问财（TQL 失败自动切换）

### 字段要点（TQL 返回列结构，21列）

- `[15]` 涨停原因揭秘长文本（**注意不是第16列**，第16列是"一字板/换手板"板型）
- `[6]` 所属行业（`@行业@` 格式，去@）
- `[12]` 概念标签（如 `芯片.机器人概念`）
- `[14]` 连板描述（如 `3天3板`）

### 文本清洗（压缩成摘要但不删内容）

1. 删除免责声明段（仅此一处删内容）
2. 通达信分隔符 `I`（题材概述与明细之间）→ 分号（前后都不是字母的独立大写I才转，不误伤 AI/AIDC/iPhone）
3. 换行 → 分号
4. **保留编号条目**（1、2、3、…不删除，维持结构）
5. 清理多余分号/空格

### 写入内容

- **extern_user.txt**：`市场|代码|108|原因摘要, [行业]|0.00`（先清旧ID=108行再追加，幂等）
  - 同步生成备用导入文件 `extdata_import_108.txt`
- **mark.dat**：[MARK]段追加 `{前缀代码}=7`（标记分值7），[TIP]段追加完整原因文本
- 市场前缀：6开头→`01`，0/3开头→`00`，4/8/9开头→`02`

### 运行

```bash
cd <工作区>/strategy && python3 update_markdat.py      # 今日
python3 update_markdat.py --yesterday                  # 昨日数据
python3 update_markdat.py --thsdk                      # 强制问财通道
```

⚠️ 依赖本地 thsdk 配置（备选通道）；mark.dat 路径默认开心果交易版通达信，可用 `--mark-dat` 覆盖。
