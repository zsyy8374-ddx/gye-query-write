# gye-query-write · 隔夜单查询写入

隔夜单（集合竞价买盘占比）查询与写入工具：交易日 **9:27** 自动运行（cron），抓取竞价阶段买盘挂单强度，写入通达信外部数据 `extern_user.txt` + ID=101 用户序列。

## 6个时点查询（买盘挂单量×100÷自由流通股）

| 时点 | ID | 挂单位置 | 含义 |
|------|-----|---------|------|
| 9:15 | 115 | 买二 | 当天隔夜单（核心） |
| 9:18 | 125 | 买二 | 918占比 |
| 9:20 | 126 | 买二 | 920占比 |
| 9:23 | 127 | 买二 | 923占比 |
| 9:24 | 128 | 买二 | 924占比 |
| 9:25 | 116 | 买一 | 当天开盘占比 |

- 数据源：同花顺问财（`9点15分买二*100/自由流通股>0.1` 等）
- 筛选：任一查询返回占比 >0.1 的股票入池
- 限频：每次查询间隔 350ms

## 写入格式

### extern_user.txt（单值外部数据）
`市场标志|代码|ID||占比值`，GBK 编码
- 市场标志：6/8开头→1(沪/科创)，0/3开头→0(深/创业)，9开头→2(北交所)
- 覆盖策略：写前先删旧的 115/125/126/127/128/116/129 行，再追加新行（其它ID数据保留）
- NaN/0 值自动跳过

### ID=101 竞价最大占比（日期-数值用户序列 v2.0 新增）
对入池每只股票取 6 时点占比的最大值，写入 `T0002/signals/signals_user_101/` 下个股二进制文件：

- 文件命名：`{市场标志}_{代码}.dat`（如 `1_600000.dat`）
- 每条记录 **8 字节**：日期 `uint32` 小端（十进制 yyyymmdd，4字节）+ 数值 `float32` 小端（4字节）
- 日期 = 数据所在交易日（默认运行日，支持 `python3 gye.py YYYYMMDD` 传参补写）
- 同日重复记录自动替换；记录按日期升序排列
- datacfg.dat 中 ID=101 名称自动注册为「竞价最大占比」（type=1 序列型）
- ⚠️ 写入后需重启通达信生效

### ID=129 竞价当天最大占比（外部单值数据 v2.1 新增）
与 101 同源同值（6时点最大值），以 extern_user.txt 单值行写入（`flag|code|129||值`，同 115/125 一类），
datacfg.dat 注册 type=0 外部（字符串/数值），重启通达信后在外部数据管理可见「竞价当天最大占比」。

## 附加动作

隔夜单占比(ID=115) TOP5 自动合并进通达信【复盘 FUPAN】板块（保留已有个股）。
